1. Extract the ZIP into a folder, then double-click Pictora.html.
   If asked which application to use, choose Google Chrome or Microsoft Edge.
   You can also use the browser's Open file command to choose Pictora.html.
2. Choose Add your image, or drag a photo onto the workspace.
3. Let Pictora prepare its colors and template. Adjust the colors and detail
   settings to suit your picture. You can also use a manual palette or a
   photograph of your paints.
4. Choose Export SVG or Export PNG. Your browser saves the finished template.

All image processing happens on your computer. No internet connection,
account, installation or activation is required. Pictora.html works by itself.

Use Google Chrome or Microsoft Edge on Windows or macOS. M7 verified Chrome
157.0.8103.79 and Edge 157.0.4341.46 on Windows Server 2025 and macOS 15.8.2
(Apple Silicon), plus Windows 11 Chrome 151 and Edge 157. Safari support is
unverified; choose Chrome or Edge on a Mac. Open the file with the browser's
Open file command if double-clicking selects Safari.
Your browser may remember the theme for this file; storage preferences can vary.
PNG edge/font rasterization can differ between macOS and Windows. SVG retains
the exact vector outlines. This ZIP contains the complete browser application.

Large photos and high-resolution PNGs need more memory. If an export fails,
reduce Canvas width and try again. SVG keeps its vector outlines.

Before printing, check the template at your intended paper size. Larger, darker
labels and fewer/smoother regions can help. Label and line sizes use output
pixels: increasing PNG width alone does not make the printed labels larger or
add detail to the processed image. Very small regions may have no visible label.
